# 英格雷斯 MVP

运行 `node server.js` 后访问 http://127.0.0.1:4173，或双击“启动英格雷斯.cmd”（需要 Node.js）。也可直接打开 index.html，建议固定使用同一浏览器与地址以保留进度。

无依赖、无登录、无远程请求。支持黑白主题、五个考试方向选择、12 个共用示例词、词卡朗读、掌握/待复习记录、12 道词义练习、学习统计、DIY 离线辅学伙伴、JSON 备份导入导出。主题、进度、人设使用 localStorage 存储。清理浏览器数据会删除记录，请定期导出。

当前考试方向仅保存目标并调整展示，未配置完整差异化考试词库。辅学伙伴为规则模板，不是大模型，不支持自由对话、作文批改或真实评分。语音依赖浏览器与系统英语语音包。尚无听力题库、口语评测、正式真题或自适应间隔重复算法。分钟数按词卡学习期间已完成的整分钟累计；学习天数为有答题/词卡操作的日期数。

代码：index.html 页面结构；style.css 响应式主题与动画；app.js 本地学习功能；server.js 固定文件本地预览服务。
