# 联网功能、隐私与使用边界 · v0.6

## 称呼、主题与游戏成绩

称呼、主题、卡片材质与动画偏好存储在本机浏览器的 `englace-experience-v1`；游戏历史存储在 `englace-arcade-history-v1`，按学习方向和游戏隔离。称呼仅用于本地问候与成绩展示，不自动进入联网辅学请求。这些数据不写入项目源文件、日志或 Git，也暂不包含在学习/工作室备份中。

排行榜最多保留 600 条，并保留各方向各游戏的历史前十。伙伴饰品配置属于工作室备份；上传外观图仍按原规则在本机重绘、默认不发送给服务商。

## 默认状态

无需账号即可使用本地词汇、写作结构检查、口语计时录音、打卡和矢量伙伴。页面不会自动连接影片服务或模型服务；资源封面与名句配图是项目原创 SVG，非远程跟踪图片。

## 密钥与请求

- 在「辅学伙伴 → 联网智能辅学」选择服务商，填写该账号已开通的准确模型 ID 与 API Key。没有内置的共享密钥。
- 密钥通过本机同源 POST 交给仅监听 127.0.0.1 的 Node 服务，只保存在进程内存。不写入 localStorage、备份、源码或日志；清除配置或停止服务即可清除本次服务配置。
- 可选环境变量：ENGLACE_AI_PROVIDER、ENGLACE_AI_MODEL、ENGLACE_AI_KEY、ENGLACE_IMAGE_MODEL。服务不自动读取 .env；不要把真实值写入仓库或命令历史。
- 接口只接受本机 Host，核对 Origin 与 Sec-Fetch-Site，POST 必须持有本机会话随机 token、使用 JSON。模型端点固定在三个服务商官方地址，不接受客户端自定义代理地址。限制输入、并发、调用频率和超时，不跟随上游重定向。
- 上游错误只返回状态与通用提示，不透传可能含密钥的服务商原始错误。服务不会执行模型返回的代码或 SVG；回复按纯文本显示，造型配置通过字段白名单校验。
- 上述保护不代替操作系统安全。能够读取本机进程内存或完全控制同源页面的程序仍可能接触数据；不要把该服务暴露到公网。

## 每种功能会发送什么

| 功能 | 外发内容 | 触发条件 |
| --- | --- | --- |
| LLM 聊天 | 当前消息、最近最多 6 条页面对话、当前学习目标与分区 | 选联网模式、确认本次发送并点击发送 |
| 写作 AI | 当前练习题目、当前草稿 | 本次勾选确认并点击 AI 建议 |
| 口语 AI | 当前题目、手动填写的转写文本 | 本次勾选确认并点击 AI 建议；**不发送录音** |
| 外观理解 | 外观描述与当前缩放后的图片（如有） | 本次勾选图片发送确认并点击 AI 理解 |
| OpenAI 文生图 | 外观文字描述 | 另填图像模型、勾选生成计费确认并点击生成；**不发送当前参考图片** |
| 在线影视 | 播放请求所需网络与浏览器信息 | 点击连接按钮或提交 BV 号 |

不自动读取其他文件、所有历史、个人学习备份或其他标签页。模型服务仍按自身数据政策处理请求，不能将本机不留日志误解为服务商零留存。OpenAI Chat 请求设置 store=false，这不是零保留承诺。请避免发送真实身份、联系方式或与学习无关的敏感内容。

## 模型与费用

支持 OpenAI / DeepSeek / 阿里云百炼北京区的兼容 Chat Completions 接口，具体模型可用性、图像能力、区域和费用由账号决定。DeepSeek 在本界面保守禁用图像输入，可选 OpenAI 或有视觉能力的千问模型理解图片。

真实文生图目前仅接 OpenAI Images API，需要另填已开通的 GPT Image 模型 ID；每次请求 1 张 1024×1024 PNG。没有订阅、充值或自动重试逻辑。未配置或请求失败时明确显示错误，不冒充已完成生成。

服务停止后内存密钥失效；若使用环境变量，再次启动可能重新载入该环境配置。清除界面配置不会删除用户自行设置的系统环境变量。

## 本地录音与图片

口语录音使用 MediaRecorder，只在用户主动点击并授权麦克风后开启，离开页面会停止麦克风轨道。音频在当前页面内存中，可自行下载；不提供自动转写或发音评分。浏览器兼容性和麦克风权限需要使用者实际确认。

上传图片只接受 PNG / JPEG / WebP，小于 8 MB，在本机重绘成最长边 384 像素 PNG，去除原始 EXIF 等元数据。普通工作室备份不含外观图片，可单独导出图片。动态效果来自本地图形动画；生成图片只是单张外观，不是多帧宠物动画。

## 桌宠范围

网页模式是应用内悬浮伙伴：六种造型、配色、上传图片、生成图片、拖动、点击学词、打开词卡。普通网页无法在其他软件上方悬浮。

可选 `npm run desktop` 通过固定 Electron 44.9.0 运行桌面学习窗口和透明置顶桌宠。第一次需要从 npm 获取运行时，不设置开机启动、不申请全局键盘监听，不制作系统级常驻服务。关闭主窗口可保留桌宠，桌宠的退出按钮结束整个程序。

Electron 页面关闭 Node 集成、开启上下文隔离与沙箱；preload 只暴露显示/收起桌宠、显示主窗口和退出。IPC 同时核验主框架、来源与已创建窗口，iframe 不获得桥接权限；限制窗口导航和外部打开地址。麦克风仅本机主窗口可请求，并显示明确授权对话框。

桌面服务使用 127.0.0.1:4174，与网页的 4173 相互独立；Electron 数据位于专用 Englace 用户数据目录。它与普通浏览器不会自动互读档案，迁移需手动导出导入备份。桌宠与桌面学习窗口通过同源存储事件同步，不通过云端传输。

## 在线影视与字幕

Sintel 预告片使用 Blender 官方地址，保留原文件，注明 Blender Foundation 与 CC BY 3.0 来源。不代理、不缓存、不绕过平台限制。B 站使用官方 iframe，示例 BV1iW411j7bn 对应公开的 Sintel 页面，但是否可嵌入和播放由 B 站决定。

跨域 iframe 无法读取内部字幕和播放时间；本项目提供可调整的中英文区域遮罩，不宣称它能控制平台字幕。原生影片播放器则支持自备双语 SRT 按时间同步，英文与中文可独立隐藏。资源加载失败时可以切换本地影片。

## 备份与 Git

「学习备份」保存原词库和学习记录；「工作室备份」保存新增打卡、草稿、手动转写与伙伴配置，另有恢复入口。工作室备份不包含 API Key、外观图片、录音、视频。清理浏览器数据会删除本地存储。

源码仓库只提交应用、测试、公版摘句、原创插画与内置资源。个人下载备份、录音、外观、草稿、缓存和凭据已通过忽略规则排除。开发时仍应检查暂存区，避免手动把私人文件添加到 Git。
