开始之前，了解这几件事。

下载需要 GitHub 登录吗？

仓库现已公开，可直接下载发行附件。应用本身不需要登录。

学习记录保存在哪里？

安装版与便携版都使用本机用户档案 %APPDATA%\Englace。移动 exe 或更新版本不会改变档案；卸载默认保留学习记录。网页版迁移请使用学习备份和工作室备份。

关于 Windows 发布者提示

本版本未使用商业代码签名证书，系统可能显示未知发布者或安全检查提示。请核对下载来源，必要时使用发行页的 SHA-256 校验文件；软件不会绕过系统安全策略。

如何退出桌宠与应用？

从托盘菜单选择“退出英格雷斯”。主窗口隐藏后，可双击托盘图标恢复。更新前请先退出旧实例。
