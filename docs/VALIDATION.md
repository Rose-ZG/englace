# v0.3 验证记录

2026-10-19，本机 Node.js 24 / Windows。

- `npm run check`：所有应用、可选 AI 接口、桌面主进程、preload 与桌宠脚本语法通过。
- `npm test`：28 项测试通过。在原测试基础上增加全部六区写作口语任务、词数、打卡连续日期、安全外观配置、工作室备份清洗、1,085 条来源/配图检查，以及 API 同源、Host、token、密钥脱敏、显式发送确认、服务商切换和图像接口测试。

- 可选 Electron 44.9.0：官方 Windows x64 发布包与 npm 官方校验摘要一致。在忽略目录内进行隐藏启动测试，主窗口、透明置顶桌宠与两个 preload 桥接均初始化成功；检查结果 alwaysOnTop=true、nodeIntegration=false、contextIsolation=true、sandbox=true。桌面测试未读取普通浏览器档案。

尚未实际采集使用者麦克风音频，录音权限与具体硬件需使用者确认；未验证所有视频编码、多显示器拖动、桌面多平台兼容性或安装包。真实图像生成需用户配置已开通的模型，本次未调用付费服务。桌面运行时不随源码提交，首次启动需下载或使用本机已校验缓存。
