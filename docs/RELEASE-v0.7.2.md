# 英格雷斯 v0.7.2 · 自选安装目录

- 安装版改为安装向导，可通过目录页的“浏览”按钮选择安装位置，例如 D 盘的应用目录。
- 安装到当前用户有写入权限的文件夹；创建桌面与开始菜单快捷方式，完成页可选择启动应用。
- 学习记录继续保存在 `%APPDATA%\Englace`，更改程序目录不会迁移或删除学习记录。
- 更新前从托盘退出旧版。如果需要改到新目录，建议先卸载旧程序（默认保留学习记录）再安装，避免多个版本并存。
- 便携版继续免安装，保留 v0.7.1 的窗口销毁异常修复。

Windows 10/11 x64。下载后可用 SHA256SUMS.txt 核验文件。
