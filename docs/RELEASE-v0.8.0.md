# 英格雷斯 v0.8.0 · 更新由你决定

- 桌面应用启动后自动检查正式新版，运行期间每 6 小时检查一次；也可通过菜单、托盘或页面顶部“检查更新”主动检查。
- 发现新版时显示提醒和更新说明，由你决定下载或稍后提醒；可关闭自动检测。
- 下载完成后仍需明确选择“退出并安装”，再打开可自选目录的安装向导。不会静默安装，也不会在退出时自动安装。
- 便携版提供校验后的下载文件，点击“打开下载文件夹”，退出旧版再自行替换原 exe。
- 下载仅来自 Rose-ZG/englace 正式发行版，要求 GitHub 资产大小和 SHA-256 匹配；安装前再次核验文件。校验失败不会安装。
- 同步最新英语信箱、ID 登录与三题密保、中英对照打卡、记忆迁移实验室和下载页视觉更新。

**旧 v0.7.2 没有内置更新器，请先手动安装一次 v0.8.0。之后发布的新版本即可通过应用提示更新。**

更新前请退出旧实例，建议导出学习、工作室及实验室备份。继续使用本机 `%APPDATA%\Englace` 学习档案，卸载默认保留数据。

[Code signing policy](https://github.com/Rose-ZG/englace/blob/main/docs/CODE-SIGNING.md)：本版仍未取得 Authenticode 签名，Windows 可能显示未知发布者。SHA-256 用于完整性校验，不等同于发布者签名。应用不会绕过系统安全提示。
