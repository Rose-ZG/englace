# 记忆迁移实验室

入口：侧栏“记忆迁移实验室”。

- 生活情境任务：当前方向的三个词优先从已有复习记录中抽取，轮换任务；将目标词原形写入自己的英文表达。只检查字面命中，不做语法、事实或语义评分。
- 信心盲测：根据中文回忆指定单词，再提交“很有把握／不太确定”。比较信心与拼写结果，提示认知盲点或信心不足，并写入现有词汇复习计划。提示不是心理诊断或能力等级评估。
- 时间胶囊：封存表达，满 24 小时后提示再次回忆，再展开原稿。可以提前查看；查看不算掌握。

表达与胶囊仅保存本地 englace-lab-v1，按学习方向区分，最多保留最近 120 条。不发送给模型。使用独立的“导出实验室备份／恢复备份”，不包含在现有学习或工作室备份内。清理浏览器、卸载或设备存储回收可能删除记录。

当前网页 App 已发布此模块；Windows 旧版安装包不会自动获得新功能。
