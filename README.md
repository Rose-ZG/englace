# 英格雷斯 Englace · v0.2

无需登录、本机存储的英语学习 MVP。黑白主题、六个考试学习区、间隔复习、分级听力与本地影视精听。无运行时第三方依赖、无跟踪、无远程接口。

## 启动

安装 Node.js 20+，双击 `启动英格雷斯.cmd`，或在项目目录运行 `npm start`，访问 http://127.0.0.1:4173。首次克隆无需 npm install。请固定使用同一浏览器与地址，**新版需要本地 HTTP 服务，不支持直接双击 index.html**。

词包按 ECDICT 标签筛选，存在跨区重合，不等同于官方最新完整考纲。学习状态、错题、复习计划、时长与听力成绩按区隔离。旧版 12 词索引会迁移为稳定英文 ID，并仅归入原方向（旧“四六级”归四级）。

- 词库书架：内置包导出；牛津、朗文、人教版官方来源入口；CSV / TSV / JSON 双语词表导入预览、去重与按区保存。TXT 从当前内置包匹配单词；不支持 PDF / 扫描件 / MDX 自动提取，不自动下载商业词典或教材。
- 单词：搜索、状态筛选、24 词分页、浏览器朗读、10 词学习。未掌握 10 分钟后复习；掌握后按 1 / 2 / 4 天递增，上限 30 天。每次选择更新本区进度。
- 听力：19 篇原创材料 / 43 题，内置本地合成音频、倍速、重听、可隐藏原文、逐句浏览器朗读、提交后解析。看原文会标记辅助练习。属于专题训练，非正式模考或官方评分。
- 影视精听：导入本地音视频 + SRT，按句虚拟截取、起止点循环、倍速、隐藏字幕、听写对照、跟读。素材用 IndexedDB 保存，不上传；不含剧集下载、真实剧集内容、自动语音识别或导出裁剪视频。
- 交互：答对光晕与上行提示音、答错轻微振动与低音反馈，音效可关，尊重系统减少动态效果偏好。
- DIY 伙伴：名字、交流风格、目标；使用当前区统计生成离线学习建议，未接入大模型。

## 数据与备份

学习、词库、人设和主题存 localStorage；媒体存 IndexedDB。可导出/恢复 v2 JSON 学习备份，支持 v1 备份迁移。JSON **不含媒体文件**，请另外保留原始音视频及字幕。清理浏览器数据会丢失本地记录。词表导入 20 MB / 20,000 词上限，受浏览器配额约束，失败时不覆盖原数据；媒体单文件 500 MB 上限。

应用本体只按需加载当前词包，列表分页；WAV 在进入课程后按需加载，不在首页预载全部音频。本地服务只监听 127.0.0.1，并支持音频 Range 请求。

## 检查与数据构建

```sh
npm run check
npm test
python scripts/build_vocab.py .cache/ecdict.csv
node scripts/build_listening.js
```

Windows 开发机上可以使用 `pwsh -File scripts/build_audio.ps1` 重建音频，需要可用的系统英语 SAPI 语音包。仓库已含生成后的音频，使用者无需重建。
