# 英格雷斯 Windows 桌面版

无需安装 Node.js、无需命令行，下载即可使用完整学习空间。

## 选择下载

- **免安装便携版**：`Englace-0.7.0-x64-portable.exe`，双击启动。
- **一键安装版**：`Englace-0.7.0-x64-setup.exe`，自动安装到当前用户并创建桌面/开始菜单快捷方式，完成后自动打开。
- **校验文件**：`SHA256SUMS.txt`。

适用于 Windows 10/11 64 位。内置六区词库、离线听力、词汇宇宙、四款游戏、写作/口语练习、多主题及独立桌宠。联网 AI 和影视功能仍按页面确认连接。

安装版与便携版共享本机 `%APPDATA%\Englace` 学习档案。更新前请从托盘菜单退出旧版；卸载默认保留数据。网页版档案需通过学习/工作室备份分别迁移。

该发行版未做商业代码签名，可能显示未知发布者或 SmartScreen 提示。请核对来源与 SHA-256，应用不会绕过系统安全策略。

仓库现已公开，可直接下载附件；英格雷斯应用本身不采用登录制。

[Code signing policy](https://github.com/Rose-ZG/englace/blob/main/docs/CODE-SIGNING.md)：免费签名申请准备中，现有附件仍未签名。
